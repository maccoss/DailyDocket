# DailyDocket v26.1.4

DailyDocket has a new icon and logo.

## New Features

- **A new icon and logo.** The app's icon, on the window, the taskbar, the notification area and
  the Start menu, is a folder holding a calendar, a checklist, an envelope and a chat bubble, on a
  dark tile; the README opens with the logo. The sources are SVG in `assets/brand`, rebuilt into
  `app.ico` and the logos by `assets/brand/build.ps1` (VectorCraft).
